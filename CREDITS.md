## Libraries

These libraries are included unchanged, each under its own license: **LibStub** (public domain),
**CallbackHandler-1.0**, **LibDataBroker-1.1** and **LibDBIcon-1.0** (the minimap button).

## Item sources

Some item sources (new quest rewards, reputation and vendor items) were checked by hand against public WoW Forever
item databases.

BiSFinder does not need any of these addons to run: the data it uses is part of BiSFinder.
